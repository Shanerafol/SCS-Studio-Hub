# 🌸 SCS StudioHub
### A Web-Based Business Management System for Shane Creative Studio

**SCS StudioHub** is a web-based business management system developed to organize and simplify the daily operations of **Shane Creative Studio**, a small creative business offering handmade flower bouquets, customized keychains, premium digital accounts, and other personalized products.

The system brings inventory management, product pricing, customer orders, cost calculations, receipt generation, planning, and subscription monitoring together in one platform.

## ✨ Features

### 📊 Dashboard
- Overview of total orders and sales
- Product performance monitoring
- Low-stock notifications
- Active warranty monitoring
- Upcoming events and daily schedules

### 📦 Inventory Management
- Add, edit, and delete craft materials
- Organize materials and premium accounts into categories
- Create, rename, and delete inventory categories
- Upload material and product images
- Track supplier costs, cost per piece, quantities, and stock levels
- Configure low-stock alerts
- Monitor available premium account slots

### 🏷️ Product Price List
- Add, edit, and delete products
- Organize Flowers, Keychains, and Premium Accounts into expandable subcategories
- Create custom product subcategories
- Display product images, names, and selling prices
- Export product catalogs in PDF or PNG format
- Display four products per row in exported catalogs

### 🛍️ Customer Order Management
- Create and manage customer orders
- Add multiple products to a single order
- Calculate order totals automatically
- Monitor payment and order statuses
- Track purchase dates and customer information
- Edit and delete orders
- Generate receipts for customer purchases

### 🧮 Price Calculator
- Calculate costs for handmade products
- Select materials directly from inventory
- Calculate material expenses based on quantity used
- Include labor costs
- Estimate premium account sharing revenue and profit
- Generate official receipt images

### 🧾 Official Receipt Generator
- Automatically generate receipt numbers
- Display customer and purchase information
- Include multiple products on one receipt
- Calculate subtotal, discount, and total amount
- Select payment methods
- Generate downloadable and printable PNG receipts

### 📅 Planner and Task Management
- Interactive calendar
- Add and manage events
- Schedule recurring activities
- Create and complete to-do lists
- Attach images and notes to tasks
- Monitor upcoming occasions

### 🛡️ Subscriptions and Warranty Monitoring
- Record customer subscriptions
- Track purchased premium accounts
- Monitor warranty duration and expiration dates
- Record customer devices
- Display active, expiring, and expired warranties

### ⚙️ Settings
- Light and dark mode
- Built-in user manual
- Administrator authentication

## 🚀 Getting Started

### Prerequisites
- Node.js and npm
- Visual Studio Code or another code editor
- Git

### Installation

1. Clone the repository**

```bash
git clone <YOUR-REPOSITORY-URL>
```

**2. Open the project folder**

```bash
cd SCS_StudioHub
```

**3. Install project dependencies**

```bash
npm run setup
```

**4. Start the development environment**

```bash
npm run dev
```

Open the local URL displayed in the terminal to access the application.

*Note: Configure any required environment variables and backend settings before running the application.*

## 🎯 Project Objectives

The system aims to:

1. Simplify inventory and product management.
2. Organize customer orders and business transactions.
3. Improve accuracy in material cost and pricing calculations.
4. Automate receipt preparation.
5. Monitor premium account subscriptions and warranties.
6. Support daily business planning and scheduling.
7. Provide a centralized platform for managing creative business operations.
